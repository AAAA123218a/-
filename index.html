กฎระเบียบ ชุมชนช่วยเหลือการตัดต่อ

ศึกษาและปฏิบัติตามกฎ 5 ข้อด้านล่างนี้ พร้อมทั้งเลือกหรือตรวจเช็กไฟล์วิดีโอก่อนส่งขอความช่วยเหลือ

กฎข้อที่ 1

วัตถุประสงค์หลักของกลุ่ม

กลุ่มนี้เป็นการช่วยเหลือการตัดต่อ แลกเปลี่ยนความรู้ และแก้ไขปัญหาวิดีโอร่วมกัน

กฎข้อที่ 2

ขอความช่วยเหลือทั่วไป

เวลาต้องการความช่วยเหลือให้พิมพ์คำสั่งแล้วส่งไฟล์ทั้งวิดีโอ

-/ช่วยตัดต่อ
กฎข้อที่ 3

คลิปความละเอียดสูง / 3 มิติ

ถ้าเป็นคลิปที่ใช้ความละเอียดสูง หรือคลิป 3 มิติ ต้องพิมพ์คำสั่งระบุเฉพาะ

(ช่วยเหลือการตัดต่อ 3 มิติ)
กฎข้อที่ 4

การเชิญคนเข้าร่วม Server

สามารถเชิญคนเข้าร่วม server นี้ได้ แต่ต้องได้รับอนุญาตก่อนจาก Admin หรือผู้สร้างเท่านั้น

กฎข้อที่ 5

มารยาทในการสื่อสาร

ที่นี่ห้ามพูดคำหยาบคาย ให้เกียรติและสร้างสภาพแวดล้อมที่เป็นมิตรต่อสมาชิกทุกคนในกลุ่ม

ส่วนเลือกไฟล์และเล่นวิดีโอตัวอย่าง

สามารถเลือกวิดีโอจากเครื่องของคุณเพื่อตรวจสอบความถูกต้องของไฟล์ก่อนส่งขอความช่วยเหลือ

ยังไม่มีไฟล์วิดีโอถูกเลือก
